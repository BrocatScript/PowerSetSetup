### 📦 PowerSetSetup is now available on WinGet

PowerSetSetup has been successfully added to the official **Microsoft WinGet** repository.

Package identifier:

`BrocatScript.PowerSetSetup`

You can now install, update, check or uninstall PowerSetSetup directly using WinGet.

#### WinGet commands

```powershell
# Install PowerSetSetup
winget install BrocatScript.PowerSetSetup

# Update PowerSetSetup
winget upgrade PowerSetSetup

# Check whether PowerSetSetup is installed
winget list BrocatScript.PowerSetSetup

# Uninstall PowerSetSetup
winget uninstall PowerSetSetup
```
